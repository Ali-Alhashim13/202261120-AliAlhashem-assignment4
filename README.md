# Ali Alhashem Portfolio - Assignment 3

## Project Overview
This is an advanced React-based portfolio application developed for **Assignment 3**. It builds upon previous assignments by introducing complex state management, external API integrations, and advanced JavaScript patterns.

### Advanced Features (Assignment 3)
- **Advanced Profile Interface**: A dynamic navigation component that expands on hover to show visitor details, including name and experience level badges, with an integrated profile reset capability.
- **GitHub API Integration**: Dynamic fetching of repository data using the Fetch API (Linked to `Ali-Alhashim13`).
- **Visitor Personalization**: Persistent onboarding flow that customizes the portfolio experience based on visitor profile.
- **Complex Data Logic**: Implementation of multi-criteria sorting (Date, Title) and advanced search algorithms.
- **Session Tracking**: A real-time session timer managing live application state.
- **Enhanced Validation**: Robust form validation using regular expressions and multi-stage error handling.
- **Performance Optimization**: Use of `useMemo` for heavy filtering operations and `AnimatePresence` for fluid transitions.

## Tech Stack
- **Framework**: React 18+ (Vite)
- **Styling**: Tailwind CSS (Utility-first, Dark Mode support)
- **Animations**: Framer Motion (Layout transitions, Gestures)
- **Icons**: Lucide React
- **API**: GitHub REST API
